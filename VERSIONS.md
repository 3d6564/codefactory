# Versions

Codefactory releases are source-installable snapshots. Install a selected tag from a trusted checkout with `./install.sh <component> ...`. The installer does not download code or report its own version.

Use semantic versioning with annotated tags in the form `vMAJOR.MINOR.PATCH`. Create a GitHub Release from the merged tag. Add the version and release date here before creating the tag. Do not release from an unmerged branch.
